# CLAUDE.md — Developer Guidelines & Repository Map

## Project Overview
Pedagogical data pipeline repository for emlyon Business School BI & DataViz courses (Power BI / Tableau). Converts raw multi-use-case source datasets into structured Cloud Data Warehouses (**Databricks Unity Catalog** and **Snowflake**).

## Architecture & Layout
```text
.
├── pyproject.toml                         # Project metadata & CLI entrypoint
├── src/emlyon_use_cases/                  # Python CLI package
│   ├── cli.py                             # Command entrypoint (emlyon-use-cases)
│   └── converter.py                       # XLSX -> CSV converter & UTF-8 normalization
├── use_cases/                             # Raw source datasets
│   ├── gdp/                               # Use Case 1: GDP vs Life Expectancy
│   ├── superstore/                        # Use Case 2: EU Superstore
│   └── allsales/                          # Use Case 3: Allsales Workshop (40,000 sales rows)
```

## Key Commands
- **Install dependencies**: `uv sync`
- **Prepare raw datasets**: `uv run emlyon-use-cases prepare`
- **Upload Databricks files**: `bash script/databricks/02_upload_files.sh ./data`
- **Upload Snowflake files**: `bash script/snowflake/02_upload_files.sh ./data`

## Principles & Rules
1. **Pedagogical Traps**: Do NOT clean raw data anomalies in SQL scripts (incomplete mapping, decimal commas, prefixed categories, junk columns). They are intentional student exercises.
2. **Read-Only BI Permissions**: Student users/service principals must NEVER have WRITE, CREATE, or MODIFY permissions.
3. **Idempotence**: All SQL scripts must use `IF NOT EXISTS` or `CREATE OR REPLACE` for safe re-execution.
4. **ANSI Safety**: Always use `TRY_CAST` and `TRY_TO_DATE` / `try_to_timestamp` to prevent query failures on dirty input string data.
